# Домашнє завдання 3 — Аналіз даних у PySpark

Проєкт читає дані користувачів, покупок і продуктів, очищує їх та аналізує витрати за категоріями.

## Вимоги

- Python 3.13
- Java 17
- PySpark 4.0.5

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py

Етапи аналізу
1. Читання CSV-файлів у DataFrame.
2. Видалення рядків із пропущеними значеннями.
3. Розрахунок загальних витрат за категоріями.
4. Розрахунок витрат за категоріями для віку 18–25 років.
5. Розрахунок частки витрат кожної категорії у відсотках.
6. Вибір трьох категорій із найбільшою часткою витрат.
Сума покупки розраховується як кількість товару, помножена на його ціну. Скриншоти результатів розміщені в папці screenshots.
